================================================================================
FPGA IMPLEMENTATION NOTES:
================================================================================
1. Each gate requires matrix multiplication: W*x + U*h + b
2. Activations: sigmoid for input/forget/output gates, tanh for cell gate
3. Memory requirements: ~89K parameters total
4. Precision: 32-bit floating point (can be quantized for FPGA)
5. Processing: Sequential (20 time steps) for each input sequence
